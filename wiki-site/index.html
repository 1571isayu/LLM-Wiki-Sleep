SCHEMA — 睡眠科學 LLM Wiki 規範

這份檔案是 LLM 維護這個 Wiki 時必須遵守的規則（對應 Karpathy LLM Wiki 的 schema 層）。

主題與範圍

  • 主題：睡眠科學入門 — 生理時鐘、睡眠週期、咖啡因
  • 目標讀者：大學同學，完全沒有生物背景
  • 不在範圍內：睡眠障礙的診斷與治療、藥物、午睡、熬夜補眠

三層結構

層 位置 誰可以改
原始資料 raw/ 只能新增，不能改內容
Wiki 頁面 wiki/ LLM 維護，人審閱
規範 SCHEMA.md 人決定

頁面類型

  • wiki/sources/S0X-*.md：每篇資料一頁摘要。
  • wiki/concepts/*.md：概念頁，一個概念一頁。
  • wiki/myths/*.md：迷思頁，固定格式「常見說法 → 研究怎麼說 → 一句話結論」。
  • wiki/glossary.md：名詞表（中文 + 英文）。
  • wiki/index.md：目錄，所有頁面都必須列在這裡。
  • wiki/log.md：時間序紀錄，每次 ingest / lint / 修正都要追加一筆。

寫作規則（ingest 時必須遵守）

  1. 每個事實都要標來源，格式 S01，對應 wiki/sources/。沒有來源的句子不能寫進概念頁。
  2. 數字一定附範圍或條件：例如半衰期寫「個人差異很大，約 2–10 小時 S04」，不能只寫單一數字。
  3. 用中文寫，專有名詞第一次出現附英文：例如「視交叉上核（suprachiasmatic nucleus, SCN）」。
  4. 區分強度：共識 / 單一研究 / 科普說法，在句尾標示（共識）（單一研究）（科普）。
  5. 不逐字複製原文：raw 只保存書目資訊、來源網址和用自己的話整理的重點；直接引用一篇最多一句、少於 15 字。
  6. 矛盾不能自己挑一個：兩個來源說法不同時，兩個都寫，並在 log 標記 CONFLICT。
  7. 白話優先：概念頁每頁都要有一個「生活例子」段落。迷思頁使用固定格式（常見說法 → 研究怎麼說 → 一句話結論），不需要生活例子。（2026-11-10 lint 後修訂）

來源可信度分級

  • A：學會共識、政府機構、同儕審查綜述
  • B：同儕審查原始研究、博士論文
  • C：科普 / 商業網站 / 部落格（只能放在迷思頁當「常見說法」的出處，不能當事實來源）

Lint 檢查清單

  • [ ] 每個概念頁的每個數字都能在對應的 source 頁找到
  • [ ] 沒有 C 級來源被當成事實來源
  • [ ] 沒有孤兒頁（沒被 index 或其他頁連到）
  • [ ] 沒有斷掉的連結
  • [ ] CONFLICT 都有處理結果
  • [ ] 用詞白話度：每個概念頁都有生活例子

咖啡因怎麼讓你醒著（Caffeine）

相關：sleep-pressure、myth-afternoon-coffee

一句話

咖啡因不會消除疲勞，它只是把「想睡」的訊號擋住。

重點

  • 咖啡因是腺苷受體拮抗劑（adenosine receptor antagonist）：它佔住 A1、A2A 受體卻不啟動它們，腺苷的「想睡」訊號就傳不出去 S04S07（共識）。
  • 被擋住的期間，腺苷照樣在累積；等咖啡因代謝掉，累積的睡意會一起回來 S07（單一來源，B 級；屬教學推論，見簡報提醒）。
  • 喝下後血中濃度達到高峰的時間：約 30 分鐘 S04，另一來源寫 30–120 分鐘 S07 → 統一寫「半小時到兩小時內」。
  • 半衰期（身體代謝掉一半所需時間）個人差異很大，約 2–10 小時 S04（共識）。
  • 影響代謝速度的因素：吸菸會加快代謝多達 50% S04；主要在肝臟由 CYP1A2 酵素代謝 S07；ADORA2A 基因變異會影響一個人對咖啡因的敏感度 S07。
  • 對睡眠的影響：一項實驗中，睡前 6 小時攝取 400 mg（約 4 杯現煮咖啡）仍顯著干擾睡眠 S04（單一研究）。
  • 咖啡因也會降低隔晚褪黑激素代謝物的量 S04。
  • 長期喝會產生耐受性，但不完全 S07；習慣喝咖啡的人隔天喝了覺得表現變好，有一部分可能只是解除了戒斷症狀，而不是真的變強 S04（綜述觀點）。

生活例子

腺苷像一群在敲門說「該睡了」的人，咖啡因是把門鎖上的保全。門外的人沒有離開，還越來越多 —— 保全下班（咖啡因代謝完）時，他們一次全湧進來 S04S07。

給簡報的提醒

  • 半衰期一律寫範圍，不寫「咖啡因半衰期 5 小時」這種單一數字。
  • S04 沒有給建議的停喝時間；簡報如果要給「建議幾點以後不喝」，必須標明是依半衰期推算的示意，不是來源建議。

生理時鐘（Circadian Rhythm）

相關：sleep-pressure、two-process-model、caffeine

一句話

身體內建一個大約 24 小時一圈的時鐘，決定你什麼時候想睡、什麼時候有精神。

重點

  • 生理時鐘節律是身體、心理、行為以約 24 小時為週期的變化，大多數生物都有 S02（共識）。
  • 主時鐘位在腦中的視交叉上核（suprachiasmatic nucleus, SCN），負責讓全身各器官的小時鐘保持同步 S02（共識）。
  • 最重要的「對時訊號」是光線；進食、運動、溫度、壓力也有影響 S02（共識）。
  • 天黑時 SCN 讓大腦分泌更多褪黑激素（melatonin），人就會想睡 S02S06（共識）。褪黑激素由松果體（pineal gland）分泌 S06。
  • 生理時鐘影響的不只是睡眠，還有荷爾蒙、體溫、食慾與消化 S02（共識）。
  • 2017 年諾貝爾生理醫學獎頒給發現時鐘基因機制的三位學者（Hall、Rosbash、Young）S02。
  • 時鐘被打亂（時差、輪班）短期會嗜睡、不專心；長期失調與肥胖、糖尿病、情緒障礙、心血管疾病等風險升高有關 S02（共識，屬關聯）。

生活例子

出國到時差 6 小時的地方，明明當地是下午，你卻想睡覺 —— 因為你的 SCN 還在照台灣時間走，要靠當地的日光慢慢「對時」S02。

給簡報的提醒

  • 不要說「生理時鐘就是褪黑激素」：褪黑激素是時鐘發出的訊號之一，不是時鐘本身。

睡眠週期（Sleep Cycle）

相關：myth-90-minutes、two-process-model

一句話

睡覺不是一路睡到底，而是在淺睡、深睡、REM 之間來回好幾輪，一輪就叫一個睡眠週期。

睡眠分期 S06（共識）

階段 英文 發生什麼事
第 1 期 NREM N1 幾分鐘，從清醒過渡到睡眠
第 2 期 NREM N2 心跳呼吸更慢、體溫下降、眼球不動
第 3 期 NREM N3（深睡） 最難叫醒，前半夜比較多
REM Rapid Eye Movement 眼球快速轉動、腦波接近清醒、多數夢在這裡、手腳肌肉暫時麻痺

一個週期多長？

  • 第一次 REM 大約在入睡後 90 分鐘出現 S06（共識）。
  • 但實驗室測量 369 位健康成人、6,064 個週期後發現：週期長度中位數 96 分鐘，95% 落在 60–150 分鐘 之間 S03（單一研究，大樣本）。
  • 變異最大的不是「人跟人之間」，而是同一晚的不同週期之間 S03。
  • 第一個週期通常比較短，REM 會越到後半夜越長 S03S06（共識）。
  • 年齡、性別、睡眠壓力都會影響週期組成；中等程度的睡前光線和交通噪音則沒有顯著影響 S03（單一研究）。

生活例子

就像下樓梯再爬回來：入睡後一路往下走到深睡（N3），再爬回到 REM，然後重新開始。整晚大約要走好幾趟，但每一趟的長度都不一樣 S06S03。

給簡報的提醒

  • 不要寫「一個週期 = 90 分鐘」，要寫「平均大約 90–100 分鐘，但變化很大」。

睡眠壓力與腺苷（Sleep Pressure & Adenosine）

相關：circadian-rhythm、two-process-model、caffeine

一句話

醒著越久，身體越「想睡」——這股越積越多的想睡感叫做睡眠壓力，腺苷是背後的重要物質之一。

重點

  • 調控睡眠的第二套系統叫睡醒恆定（sleep-wake homeostasis）：清醒每多一小時，睡眠驅力就更強；長時間沒睡之後，睡得會更久更深 S06（共識）。
  • 腺苷（adenosine）被廣泛認為是體內調節睡眠的物質 S05（共識），它會讓人想睡 S06。
  • 腺苷來自能量分子（如 ATP）的分解，在長時間清醒時累積，在深睡時被清除，睡眠壓力因此下降 S07（單一來源，B 級）。
  • 腺苷透過腦中的 A1、A2A 受體作用：A1 抑制讓人清醒的神經元，A2A 協助進入睡眠 S07（單一來源，B 級）。

生活例子

把腺苷想成一個沙漏：從早上起床開始，沙子一直往下掉（腺苷累積）；到了晚上沙子堆滿了，你就很想睡。睡一覺，沙漏被翻回來重新開始 S07。

給簡報的提醒

  • 「腺苷隨清醒累積」目前只有 S07（B 級）直接支撐；NINDS（S06）只說腺苷讓人想睡。簡報可以講，但要用「研究認為」的語氣。

雙歷程模型：兩套系統一起決定你什麼時候睡

相關：circadian-rhythm、sleep-pressure

一句話

你想不想睡，是「生理時鐘（幾點了）」和「睡眠壓力（醒多久了）」兩個力量疊加的結果。

重點

  • NINDS 把睡眠的調控分成兩套系統：生理時鐘節律（circadian rhythms）與睡醒恆定（sleep-wake homeostasis）S06（共識）。
  • 生理時鐘以 24 小時為基礎，管清醒程度、體溫、代謝、荷爾蒙 S06。
  • 睡醒恆定記錄你「欠了多少睡眠」，醒越久越強 S06。
  • 腺苷可能也會影響生理時鐘，兩套系統之間可能透過腺苷互相連結——這仍是研究中的問題 S05（研究進行中）。

生活例子

熬夜到凌晨 3 點很想睡（壓力高 + 時鐘在低谷）；但如果撐到早上 8 點，反而覺得「好像又醒了」——睡眠壓力其實還在，只是生理時鐘進入白天模式把你撐起來 S06S02。

給簡報的提醒

  • 這頁是串起其他概念的「骨架頁」，簡報的結構可以照這頁排：先講時鐘，再講壓力，最後講咖啡因怎麼干擾壓力。
  • 「兩個力量疊加」的生活例子屬於教學上的推論，不是來源原文說法；簡報上用「可以這樣理解」的語氣。
wiki/myths/myth-8-hours.md

迷思：每個人每晚一定要睡滿 8 小時

相關：two-process-model

常見說法

「睡眠標準就是 8 小時，少一點都不行。」

研究怎麼說

  • 美國睡眠醫學會與睡眠研究學會的共識是：18–60 歲成人應規律地睡 7 小時以上 —— 底線是 7，不是 8 S01（共識）。
  • 共識沒有設上限；年輕人、正在補眠或生病的人，睡超過 9 小時可能是合適的 S01（共識）。
  • 每個人需要的睡眠量不同，受基因、行為、健康、環境影響 S01（共識）。
  • NINDS 寫的是成人「7–9 小時」S06（共識）。
  • 時數之外，睡眠品質、時間點、規律性也很重要 S01。
  • 長期睡不到 7 小時，與肥胖、糖尿病、高血壓、憂鬱、意外增加等有關聯 S01。

一句話結論

8 小時不是標準答案；比較準確的說法是「至少 7 小時，而且要規律」。

來源差異（CONFLICT-01，已處理）

S01 寫「7 小時以上、不設上限」，S06 寫「7–9 小時」。兩者下限一致；差在上限。處理方式：簡報寫「至少 7 小時（多數建議落在 7–9 小時）」，兩個來源都標。

wiki/myths/myth-90-minutes.md

迷思：睡眠週期剛好 90 分鐘，照 90 分鐘倍數睡就會神清氣爽

相關：sleep-cycle

常見說法

線上「睡眠計算器」假設每個週期剛好 90 分鐘、入睡要 15 分鐘，建議你睡 6、7.5 或 9 小時，在週期結束時醒來就不會昏沉 S08（科普/工具網站，C 級，只作為說法出處）。

研究怎麼說

  • 第一次 REM 大約在入睡後 90 分鐘出現 —— 「90 分鐘」這個印象確實有來源 S06（共識）。
  • 但大樣本實驗室研究（369 人、6,064 個週期）測到週期中位數 96 分鐘，95% 落在 60–150 分鐘 S03（單一研究）。
  • 同一晚裡，前後週期的長度差異最大（變異係數約 29%），比人與人之間的差異還大 S03。
  • 第一個週期通常較短，之後 REM 越來越長 S03S06。
  • 所以「入睡時間 + N × 90 分鐘」算出的起床時間，誤差可能遠超過一個睡眠階段的長度。（推論：根據 S03 的變異範圍）

一句話結論

「90 分鐘」來自第一次 REM 出現的大約時間 S06，但實測週期中位數約 96 分鐘、而且忽長忽短 S03；與其算週期，不如睡夠、睡得規律 S01。

備註

連 S08 自己的頁面也承認週期長度因人而異、計算器只是參考 —— 迷思的問題常常不是來源「說錯」，而是被簡化轉述後只剩下「剛好 90 分鐘」。

wiki/myths/myth-afternoon-coffee.md

迷思：下午喝咖啡，晚上就不會影響睡眠

相關：caffeine

常見說法

「咖啡因幾個小時就退了，下午三四點喝沒差。」

研究怎麼說

  • 咖啡因的半衰期個人差異很大，約 2–10 小時 S04（共識）。也就是說，對代謝慢的人，下午 4 點喝的咖啡，到半夜可能還剩一半以上。（推論：依半衰期換算）
  • 實驗中，睡前 6 小時攝取 400 mg 咖啡因（約 4 杯現煮咖啡），睡眠仍明顯受干擾 S04（單一研究，劑量偏高）。
  • 有研究甚至發現早上 7 點攝取 200 mg，當晚睡眠效率與總睡眠時間也下降 S04（單一研究）。
  • 吸菸、基因等因素都會改變代謝速度與敏感度 S04S07。

一句話結論

「下午喝沒差」因人而異；對代謝慢或敏感的人，下午的咖啡很可能還在影響晚上的睡眠。

注意

  • Drake 研究的劑量 400 mg 比一般一杯咖啡高很多，簡報要講清楚，避免誇大。
  • 來源沒有給「幾點以後不能喝」的官方建議。

"""Post-generation check: does every slide say only what the wiki's raw sources support?

  C1 a cited source ID does not exist in raw/
  C2 a number on a slide cannot be found in the raw file(s) of the sources cited in that block
     (blocks without their own citation fall back to the slide's data-src)
  C3 a C-grade source is cited on a slide that is not a myth slide
  C4 the slide's data-src does not match the citations actually shown
  C5 a phrase the wiki marked as forbidden appears (e.g. a single-number half-life)
Blocks inside [data-nocheck] are illustrative (charts, formula-based estimates) and skipped.
"""
import re, sys
from pathlib import Path
from bs4 import BeautifulSoup

ROOT = Path(__file__).resolve().parent
raw = {p.name[:3]: p.read_text(encoding="utf-8") for p in (ROOT / "raw").glob("S0*.md")}
grade = {k: re.search(r"^grade:\s*([ABC])", v, re.M).group(1) for k, v in raw.items()}
soup = BeautifulSoup((ROOT / "slides/sleep-slides.html").read_text(encoding="utf-8"), "html.parser")
FORBID = [(r"半衰期[^。]{0,6}(約|是|為)\s*\d+\s*小時", "single-number half-life"),
          (r"週期\s*(=|就是|剛好是)\s*90", "cycle stated as exactly 90"),
          (r"平均\s*5\s*小時", "unsourced 'average 5 hours'")]
NUM = re.compile(r"(?<![A-Za-z0-9.,])(\d+(?:,\d{3})*(?:\.\d+)?)(?![A-Za-z0-9])")
issues = []
for idx, s in enumerate(soup.select("section.slide"), 1):
    for nc in s.select("[data-nocheck]"):
        nc.decompose()
    slide_src = s.get("data-src", "").split()
    shown = set()
    for blk in s.select("li, p, h2, h3, .big, .verdict"):
        if blk.find(["li", "p"]):
            continue
        cites = [c.get_text(strip=True) for c in blk.select(".cite")]
        shown.update(cites)
        for c in blk.select(".cite, .tag"):
            c.extract()
        text = blk.get_text(" ", strip=True)
        if blk.get("class") and "big" in blk["class"]:
            sib = blk.find_next_sibling()
            cites = cites or [c for c in re.findall(r"S0\d", str(sib))]
        for c in cites:
            if c not in raw:
                issues.append((idx, "C1", f"cites missing {c}"))
        pool = cites or slide_src
        rawtext = " ".join(raw.get(c, "") for c in pool)
        for n in NUM.findall(text):
            if not pool:
                issues.append((idx, "C2", f"number {n} with no source: {text[:40]}"))
            elif n not in rawtext:
                issues.append((idx, "C2", f"number {n} not in {'/'.join(pool)}: {text[:40]}"))
        for pat, why in FORBID:
            if re.search(pat, text):
                issues.append((idx, "C5", f"{why}: {text[:40]}"))
    for c in shown:
        if grade.get(c) == "C" and not s.get("data-wiki", "").startswith("myths/"):
            issues.append((idx, "C3", f"C-grade {c} on non-myth slide"))
    if set(slide_src) != shown and slide_src:
        issues.append((idx, "C4", f"data-src {sorted(slide_src)} vs shown {sorted(shown)}"))
for i in issues:
    print(f"slide {i[0]:>2}  {i[1]}  {i[2]}")
print(f"\n{len(issues)} issue(s)")
sys.exit(1 if issues else 0)

"""Programmatic lint for the sleep-science LLM Wiki.

Checks (from SCHEMA.md):
  L1 broken [[links]]
  L2 orphan pages (not linked from index or any other page)
  L3 citations [Sxx] that point to a missing source
  L4 C-grade sources cited outside a myth page's "常見說法" section
  L5 numbers on concept/myth pages that cannot be found in the cited raw file(s)
  L6 concept/myth pages missing a 生活例子 section
"""
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent
WIKI = ROOT / "wiki"
RAW = ROOT / "raw"

pages = {p.stem: p for p in WIKI.rglob("*.md")}
raw_by_id = {p.name[:3]: p for p in RAW.glob("S0*.md")}
grade = {}
for sid, p in raw_by_id.items():
    m = re.search(r"^grade:\s*([ABC])", p.read_text(encoding="utf-8"), re.M)
    grade[sid] = m.group(1) if m else "?"

issues = []
linked = set()

for name, path in pages.items():
    text = path.read_text(encoding="utf-8")
    rel = path.relative_to(ROOT)
    # L1
    for link in re.findall(r"\[\[([^\]]+)\]\]", text):
        linked.add(link)
        if link not in pages:
            issues.append(("L1", rel, f"broken link [[{link}]]"))
    # L3
    for sid in set(re.findall(r"\[(S0\d)\]", text)):
        if sid not in raw_by_id:
            issues.append(("L3", rel, f"cites missing source {sid}"))
    is_content = path.parent.name in ("concepts", "myths")
    if not is_content:
        continue
    # L4
    sections = re.split(r"^## ", text, flags=re.M)
    for sec in sections:
        title = sec.splitlines()[0] if sec else ""
        for sid in set(re.findall(r"\[(S0\d)\]", sec)):
            if grade.get(sid) == "C" and "常見說法" not in title:
                issues.append(("L4", rel, f"C-grade {sid} used as evidence in section '{title}'"))
    # L5 — check each line's numbers against that line's cited raw sources
    for line in text.splitlines():
        cites = re.findall(r"\[(S0\d)\]", line)
        if not cites or "推論" in line:
            continue
        nums = re.findall(r"(?<![A-Za-z0-9.])(\d+(?:\.\d+)?)(?![A-Za-z0-9])", line)
        nums = [n for n in nums if not re.fullmatch(r"0\d", n)]
        raw_text = " ".join(raw_by_id[s].read_text(encoding="utf-8") for s in cites if s in raw_by_id)
        for n in nums:
            if n not in raw_text:
                issues.append(("L5", rel, f"number {n} not found in {','.join(cites)}: {line.strip()[:60]}…"))
    # L6
    if path.parent.name == "concepts" and "生活例子" not in text:
        issues.append(("L6", rel, "no 生活例子 section"))

# L2
for name, path in pages.items():
    if name in ("index", "log"):
        continue
    if name not in linked:
        issues.append(("L2", path.relative_to(ROOT), "orphan page"))

for code, rel, msg in sorted(issues, key=lambda x: (x[0], str(x[1]))):
    print(f"{code}  {rel}  {msg}")
print(f"\n{len(issues)} issue(s)")
sys.exit(1 if issues else 0)
